Shelfie

Find any screenshot by the words inside it.

Shelfie reads the text inside every screenshot on your Android phone and makes it searchable — a receipt, an OTP, a booking ID, a wifi password, one search away. Each result carries its next step too: copy the code, open the link, add the date to your calendar.

It ships with no internet permission at all. Not restricted — absent. Android won't let it open a network connection, so your screenshots physically cannot be uploaded anywhere. The code is public, so you can verify it yourself.

Fast on budget phones. One payment, no subscription, no ads, no account.
