# Product Hunt launch assets

Generated by [`tools/producthunt/render.js`](../../tools/producthunt/) from the HTML
in that folder — the same "generate, don't hand-draw, so the brand can't drift"
approach as `tools/store_graphics.py`. The logo is the exact launcher-icon geometry;
the palette mirrors `BrandColors` in `core/designsystem`.

| File | Size | Use |
|---|---|---|
| `logo-240.png` | 240×240 | Product Hunt thumbnail / logo |
| `gallery-1-find.png` | 1270×760 | Gallery 1 — what it does |
| `gallery-2-privacy.png` | 1270×760 | Gallery 2 — the no-internet hook (lead with this) |
| `gallery-3-speed.png` | 1270×760 | Gallery 3 — speed on cheap hardware |
| `gallery-4-actions.png` | 1270×760 | Gallery 4 — actions on each screenshot |
| `gallery-5-price.png` | 1270×760 | Gallery 5 — one-time pricing |

**These gallery images are branded caption cards, not app screenshots.** That is
legitimate for Product Hunt, but the strongest listing interleaves 2–3 real captures
from the live app. Capture those on a device and drop them into the gallery alongside
these.

Regenerate after any brand change:

```bash
CHROME=/path/to/chrome PLAYWRIGHT=/path/to/playwright-core \
  node tools/producthunt/render.js
```
