# Play Store feature screenshots

1080×1920 caption slides, generated by [`tools/playstore/render.js`](../../tools/playstore/)
from HTML — same generate-don't-draw approach as `tools/store_graphics.py`, so they
can't drift from the brand. Prompted by launch feedback that raw, uncaptioned
screenshots underperform: captioned feature slides convert better and let the listing
lead with the privacy differentiator.

Recommended upload order (Play Console → Grow → Store presence → Main store listing →
Phone screenshots):

| # | File | Caption |
|---|---|---|
| 1 | `play-1-privacy.png` | No internet permission. At all. |
| 2 | `play-2-search.png` | Search the text inside your screenshots |
| 3 | `play-3-actions.png` | Sorted automatically — with an action on each |
| 4 | `play-4-cleanup.png` | Clear out duplicate and blurry screenshots |
| 5 | `play-5-price.png` | One payment. ₹250. No subscription. |

**These are promotional caption slides, not device captures.** Play accepts styled
promo screenshots, but the strongest listing also shows the real UI — capture 2–3 real
screens from the live app (search results, the shelf, the detail sheet) and interleave
them with these.

Regenerate after any brand or copy change:

```bash
CHROME=/path/to/chrome PLAYWRIGHT=/path/to/playwright-core \
  node tools/playstore/render.js
```
